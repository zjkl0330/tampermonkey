# 11 · 百度网盘个人盘接入（v1.12.0）

> 起因：「百度网盘登录后个人网盘主页也是我看你是都没做是吧」。核实属实：`@match` 里百度只有
> `pan.baidu.com/s/*`、`share/*`、`yun.baidu.com/s/*`，个人盘 `/disk/main` 从未注入。

## 一、为什么百度个人盘不能照抄 123 / 迅雷

123 和迅雷都能直接用浏览器登录态（`localStorage` 令牌），百度不行：

| 通道 | 依赖 | 问题 |
| --- | --- | --- |
| 网页版 `/api/download`、`/api/sharedownload` | `bdstoken` + 动态 `sign` + `timestamp` + `jsToken` | 签名随前端改版变化，且 `bdstoken` 在页面全局变量里，改版就断 |
| `/api/list` 列目录 | Cookie（BDUSS 是 HttpOnly，页面 JS 读不到，但 fetch 会自动带） | 只能列目录，取链还得走上面那套 |
| **开放平台 OAuth `access_token`** | 一次授权，30 天 | 列目录 + 取链都认它，接口稳定 |

脚本 v1.8.0 做百度分享页时已经接了 OAuth（`filemetas` + `dlink` + `access_token`），个人盘直接复用，
不需要新逆向。代价是用户要多点一次「一键授权百度网盘」。

## 二、接口

```
列目录  GET https://pan.baidu.com/rest/2.0/xpan/file?method=list
        &access_token=…&dir=%2F&order=name&start=0&limit=1000&web=1

取链    GET https://pan.baidu.com/rest/2.0/xpan/multimedia?method=filemetas&dlink=1
        &fsids=%5B<fs_id>%5D&access_token=…

校验    GET https://pan.baidu.com/rest/2.0/xpan/nas?method=uinfo&access_token=…
```

返回：

```json
{"errno":0,"list":[{"fs_id":111,"path":"/相册","server_filename":"相册","isdir":1,"size":0}]}
```

要点：

- `dir` 是**路径**（`/`、`/相册`），不是 fid —— 所以面板里目录的 `fid` 直接存 path，`stack` 天然可用。
- `isdir=1` 是目录，文件用 `fs_id` 取链。
- 分页用 `start` / `limit`，满 1000 说明可能还有下一页（脚本最多翻 50 页）。
- `dlink` 必须追加 `&access_token=`（百度硬性要求，不是 Header），下载还要 `User-Agent: pan.baidu.com`。
  这两件事 v1.8.0 的 `_attachToken` / `BAIDU_DL_UA` 已经在做，直接复用。
- `errno`：`-6` 未登录、`31045` token 失效、`105` 目录不存在。前两个都会清掉本地令牌并提示重新授权。

## 三、无 Cookie 实测

```
GET /rest/2.0/xpan/file?method=list&dir=%2F&web=1          → 未带 token 时无法通过
GET /api/list?dir=%2F&num=10…                              → {"errno":-6}   未登录
GET /api/gettemplatevariable?fields=["bdstoken"]           → {"errno":-6,"result":[]}
```

`errno -6` 而不是 404，说明路径与参数形态正确，只差凭据。也侧证了「Cookie 只能列目录」这条路在无账号时不可验证，
最终选了 OAuth 通道，避免写出「看起来能用但一改版就废」的代码。

## 四、目录跟随

百度个人盘也是 SPA，切目录不换 URL。页面自己列目录走的是 `/api/list?dir=%2F…`，所以 hook 这支请求即可：

```js
if (isBD && /\/api\/list(\?|$)/.test(s)) {
  const mb = s.match(/[?&]dir=([^&]*)/);
  if (mb) pageMineDir = decodeURIComponent(mb[1] || '/');
}
```

两个细节：

1. 脚本自己的 xpan 请求带 `access_token`，必须先 `if (/access_token=/.test(s)) return;` 排除，否则会自己跟丢自己。
2. 根目录是 `/` 而不是 `0`，`followMineDir()` 里要一并跳过，否则每次都重读根目录。

## 五、实测（Playwright 打桩）

| 场景 | 结果 |
| --- | --- |
| 已授权 + 根目录 | 标题「测试号」，副标题「1 个文件，1 个文件夹」，标签「已授权」 |
| 下钻「相册」 | 面包屑「我的云盘/相册」，列表变成子目录文件 |
| 勾选 + 复制 | 剪贴板得到 `https://d.pcs.baidu.com/file/abc?fid=222&access_token=…`（自动拼 token） |
| 无令牌 | 标签「未授权」，面板给「一键授权百度网盘」+「我已登录，重试」两个按钮 |
| 令牌失效（31045） | 清本地令牌，标签「登录失效」，提示重新授权 |
| 123 / 迅雷回归 | 全部照旧 |

## 六、已知限制

- 真实账号下的 `xpan/file?method=list` 是否对免费号限速 / 限目录深度，未验证（协议层 OK）。
- `dlink` 约 8 小时，过期后需重新取链；面板缓存在 `state.links`，刷新页面即清。
- 百度个人盘**不需要网页登录**也能用——只要有授权令牌；反过来，只登录网页但没授权，就只能看到「未授权」提示。
- 走浏览器直下会被百度按 UA 拦（>50MB 报 31326）；脚本在有令牌时自动切分片引擎（GM 通道可设 UA），这条沿用 v1.8.0 的判断。
