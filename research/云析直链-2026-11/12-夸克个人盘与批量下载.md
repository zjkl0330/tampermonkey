# 12 · 夸克个人盘与批量下载（v1.14.0）

> 起因：盘点「还剩什么没做」时，夸克是唯一「协议已经吃透、只差搬一遍」的平台——
> 它和 UC 共用 `clouddrive`，个人盘接口只差域名和 `pr` 参数。顺手一起补的还有
> 「勾了一堆文件却只能一个个点下载」这个体验缺口。

## 一、接口确认（先探再写）

无 Cookie 直接打两个候选域名，看谁回「要求登录」而不是 404：

```bash
# 列目录
GET https://drive-pc.quark.cn/1/clouddrive/file/sort
    ?pr=ucpro&fr=pc&pdir_fid=0&force=0&_page=1&_size=50
    &_fetch_total=1&_fetch_sub_dirs=0&_sort=file_type:asc,updated_at:desc
→ {"status":401,"code":31001,"message":"require login [guest]"}

# 取链
POST https://drive-pc.quark.cn/1/clouddrive/file/download?pr=ucpro&fr=pc&sys=win32&ve=3.23.2
     body {"fids":["1"]}
→ {"status":401,"code":31001,"message":"require login [share missing]"}
```

`pc-api.quark.cn` 返回空（域名不存在），所以夸克个人盘的正确域是 `drive-pc.quark.cn`，
UC 才是 `pc-api.uc.cn`。`31001 / require login` 说明路径、参数、鉴权方式都对，缺的只是登录态。

## 二、和 UC 到底差在哪

| 项 | UC | 夸克 |
| --- | --- | --- |
| 接口域 | `pc-api.uc.cn` | `drive-pc.quark.cn` |
| `pr` | `UCBrowser` | `ucpro` |
| UA | `UA_UC` | `UA_QUARK`（`quark-cloud-drive/2.5.20 ... Electron`） |
| 登录态 Cookie | `__puus`（域 `uc.cn`） | `__puus`（域 `quark.cn`） |
| 取链 body | `{fids:[...]}` | `{fids:[...]}` |

其余（`file/sort` 的 `pdir_fid`、返回的 `data.list[].fid / file_name / dir`、
`data[0].download_url`）完全一致。所以实现上是把 UC 的 `mine*` 方法整组搬过来改三处常量，
`list` / `link` 仍然只在 `ctx.mine` 时分流，**分享链路一行没动**。

`__puus` 是 HttpOnly，`document.cookie` 读不到，必须走 `GM_cookie`。找不到就直接
`authFailed = 'expired'`，标签显示「登录失效」，不要装作在加载。

## 三、批量下载已选

原来只有「全选 / 复制已选 / 导出 Aria2」，想下 10 个文件得点 10 次「下载」。

设计取舍：

- **取链串行**，间隔 600ms（浏览器直下模式 900ms）——频控是按请求算的，并发取链最容易撞。
- **下载不排队等**：`resolveLink` 拿到链后直接 `DL.start()` 不 await，
  已启动的任务由 `DL` 自己按运行中任务数平分线程（8 / running），不会一次铺开几十个连接。
- **浏览器模式必须一个一个触发**：手机 / 无 GM 环境走 `openInTab`，并发弹窗会全被拦。
- **上限 20 个**：超过直接提示改用「导出 Aria2」，不硬扛。文件名、大小、断点续传都交给外部下载器更合适。

窄屏（≤560px）把搜索框挤到第二行，五个按钮独占一行，否则 430px 宽下面板会把
「全选 / 复制已选 / 下载已选 / 导出 Aria2 / 刷新」折成两截。
