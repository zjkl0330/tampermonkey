## 二、一手实测（本项目自有）

所有接口结论都来自这些动作，不引用二手博客：

| 平台 | 实测方式 | 关键证据 |
| --- | --- | --- |
| 夸克 | 真实分享文件夹，递归 + 8 线程分片 | 最终文件 MD5 与源一致 |
| UC | 真实分享 | CDN 200，`Content-Length` = 列表 size |
| 123 | 匿名 + 登录 | `5112` |
| 115 | 游客 | `990001` |
| 天翼 | 游客 | `InvalidSessionKey` |
| 139 | Playwright 注入 + Web Crypto 解密 | `resultCode: 0`，三级目录列通 |
| 阿里 | 匿名 | `AccessTokenInvalid` |
| 百度 | 游客 + 页面上下文 dump | `errno=-6`；`locals` 键名清单 |
| 迅雷 | Python 复刻签名 + Playwright 截获 token + 逐层爬目录 | `captcha_token` 743 字符；`share_status: OK`；`web_content_link` 为空 |
| 蓝奏 | 算法复刻 | `acw_sc__v2` 通过，卡 `lanrar.com` 人机验证 |

详细数据见 [`01-平台协议实录.md`](./01-平台协议实录.md)。

## 四、工具链

| 工具 | 用途 |
| --- | --- |
| Chromium 124 + Playwright | 页面上下文探查、token 截获、端到端回归 |
| `--host-resolver-rules` + `--ignore-certificate-errors` | 本地 HTTPS 测试台域名映射 |
| Python `urllib` | 协议最小化复现（不带任何浏览器因素） |
| Node `crypto` | 校验自实现 MD5 与标准实现一致 |
| curl | 单请求验证，排除脚本层干扰 |
